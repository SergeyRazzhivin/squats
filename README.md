# Приседания 🏋️ — семейный трекер

Простое приложение: папа, мама и дочка записывают, сколько раз присели каждый день.
Общая таблица и графики. **Хостинг и хранение данных — бесплатно** (GitHub).

- Приложение — один файл `index.html` (без сборки), графики на Chart.js.
- Данные — файл `data.json` в **приватном** GitHub-репозитории (общие для всех).
- Доступ — личный токен у каждого, хранится только в браузере его телефона.

---

## Настройка с нуля (примерно 10 минут, один раз)

### 1. Репозиторий с данными (приватный)

1. Создайте репозиторий на GitHub: **New repository** → имя, например `squats-data` → **Private** → Create.
2. Добавьте в него файл `data.json` со стартовым содержимым (можно взять [`data.example.json`](data.example.json)):
   ```json
   { "version": 1, "people": ["Папа", "Мама", "Дочка"], "days": {} }
   ```
   Имена в `people` можно поменять под свою семью.

### 2. Репозиторий с приложением (публичный) + публикация

1. Создайте **публичный** репозиторий, например `squats`, и положите туда `index.html`.
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch → ветка `main`, папка `/ (root)` → Save.**
3. Через минуту GitHub покажет ссылку вида `https://ВАШ-ЛОГИН.github.io/squats/`. Это и есть приложение.

> В публичном репозитории лежит **только код** — ни данных, ни токенов там нет.

### 3. Токен доступа (у каждого члена семьи свой)

1. GitHub → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.**
2. **Repository access → Only select repositories →** выберите `squats-data`.
3. **Permissions → Repository permissions → Contents → Read and write.**
4. Сгенерируйте и скопируйте токен (он показывается один раз).

### 4. Первый запуск

1. Откройте ссылку приложения на телефоне.
2. Нажмите **⚙** (или появится экран настройки):
   - **Владелец репозитория** — ваш GitHub-логин (владелец `squats-data`);
   - **Имя репозитория** — `squats-data`;
   - **Токен** — вставьте свой токен.
3. Сохраните, выберите «кто записывает» — и пользуйтесь.

Каждый член семьи делает шаги 3–4 на своём устройстве со **своим** токеном. Данные у всех общие.

## Как пользоваться

- **Сегодня** — кнопки `+10 / +20 / +50 / +100`, `+` / `−` поштучно, или точное число.
- **История** — таблица по дням; нажмите на ячейку, чтобы исправить число.
- **Графики** — динамика по дням у каждого и общее сравнение.
- **⟳ Обновить** — подтянуть изменения, сделанные другими.

## Безопасность и приватность

- Токен хранится только в браузере устройства (`localStorage`), в коде сайта его нет.
- Данные — в приватном репозитории, посторонним не видны.
- Потеряли телефон? Отзовите токен: **Settings → Developer settings → Personal access tokens →** удалить нужный. Остальные продолжат работать.

## Поменять состав семьи

Отредактируйте список `people` в `data.json` (через сайт GitHub: открыть файл → ✏️ → Commit).

---

## Альтернатива попроще (без приватности)

Можно положить `data.json` в тот же **публичный** репозиторий, что и код, — настройка короче, но числа приседаний будут видны в интернете. Для этого в настройках укажите имя публичного репозитория вместо `squats-data`.
